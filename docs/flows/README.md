# User Flows

These flows translate the product requirements into end-to-end behavior.

- [Player discovery](player-discovery.md) — find a venue, court, and eligible slot.
- [Booking](booking.md) — request, lock, approve, reject, expire, cancel, and complete a booking.
- [Gym owner booking management](owner-booking-management.md) — configure venues and courts, then review booking requests.

Use [Product Requirements](../product/requirements.md) as the source of truth for requirement identifiers and acceptance criteria.
